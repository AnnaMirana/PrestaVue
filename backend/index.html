⚙️ Étapes d'Import

1. Produits
   • Lire le CSV
   • Valider chaque ligne
   • Créer les catégories
   • Insérer dans BD
   ↓
2. Détails Produits
   • Lire le CSV
   • Valider les variantes
   • Créer le stock
   • Insérer dans BD
   ↓
3. Clients (+ Commandes)
   • Lire le CSV
   • Vérifier pas de doublons
   • Créer adresses
   • Parser et créer commandes
   ↓
4. Images
   • Dézipper le fichier ZIP
   • Valider les images
   • Sauvegarder les fichiers
   • Référencer dans BD
